THREAT HUNTING FINDINGS
Author: Wamba José
Lab: Threat Hunting with MITRE ATT&CK, Splunk, Sigma and Atomic Red Team


HUNT 1: T1087.001 LOCAL ACCOUNT DISCOVERY

Tactic: Discovery (TA0007)
Emulation: Atomic Red Team test "Enumerate all accounts on Windows (Local)"

Findings:
whoami.exe was launched by powershell.exe.
The commands net user, net localgroup and cmdkey /list were launched by cmd.exe.
All of them ran under the account WIN10-LAB\wamba within a few seconds.

Detection logic: three or more different discovery commands (net, whoami, cmdkey) within five minutes.
Sigma rule: sigma-rules\T1087.001_local_account_discovery.yml
Splunk alert: "T1087.001 - Local Account Discovery", runs every hour, severity Medium.
Result: the alert fired automatically after the emulation.


HUNT 2: T1136.001 CREATE LOCAL ACCOUNT

Tactic: Persistence (TA0003)
Emulation: Atomic Red Team test "Create a new user in a command prompt"

Process chain seen in Sysmon:
cmd.exe ran: net user /add "T1136.001_CMD" "T1136.001_CMD!"
net.exe then ran: net1 user /add "T1136.001_CMD" "T1136.001_CMD!"

Matching Windows Security events:
2026-11-17 03:11:30.905 UTC, Event 4720: the account T1136.001_CMD was created by wamba.
2026-11-17 03:11:30.977 UTC, Event 4732: the account was added to the Users group by wamba.

What this tells us:
The net.exe to net1.exe chain confirms the account was created from the command line.
The backdoor password is visible in clear text in the command line.
The Security event 4720 happens in the same second as the Sysmon event, which confirms the attack from two independent log sources.

Benign finding:
On 2026-11-16, Event 4732 showed an account added to the "Event Log Readers" group.
This was legitimate admin work: giving the Splunk forwarder permission to read event logs.
I investigated it and closed it as benign.

Sigma rule: sigma-rules\T1136.001_create_local_account.yml
Splunk alert: "T1136.001 - Local Account Created", runs every hour, severity High.


HUNT 3: T1547.001 REGISTRY RUN KEYS

Tactic: Persistence (TA0003)
Emulation: Atomic Red Team test "Reg Key Run"

Hypothesis:
If an attacker sets up persistence through a Run key, Sysmon will record a registry
value being set (EventCode 13) on the key CurrentVersion\Run, and the reg.exe process
(EventCode 1) that wrote it.

Findings:
reg.exe, launched by cmd.exe, ran REG ADD on HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
with the value "Atomic Red Team" pointing to C:\Path\AtomicRedTeam.exe.
Sysmon EventCode 1 (the command, 04:06:14.527 UTC) and EventCode 13 (the registry write,
04:06:14.559 UTC) happened 32 milliseconds apart.
Hypothesis confirmed.

Sigma rule: sigma-rules\T1547.001_registry_run_key.yml
Splunk alert: "T1547.001 - Registry Run Key Persistence", runs every hour, severity High.


HUNT 4: T1053.005 SCHEDULED TASK

Tactic: Persistence and Execution (TA0003, TA0002)
Emulation used: schtasks /create /tn "spawn" /tr cmd.exe /sc once /st 23:59 (manual, equivalent to Atomic T1053.005)

Hypothesis:
If an attacker creates a scheduled task, Sysmon will record schtasks.exe started with
/create (EventCode 1), and Windows will log Security Event 4698 (a scheduled task was created).

Preparation:
Event 4698 is not logged by default. I enabled it with:
auditpol /set /subcategory:"Other Object Access Events" /success:enable /failure:enable

Findings:
schtasks.exe was launched with /create to make a task named "spawn" that runs cmd.exe.
Windows Security Event 4698 confirmed the task \spawn was created on Win10-lab by the account wamba,
at the same time as the Sysmon process event (05:06:51 UTC).
Hypothesis confirmed.

Sigma rule: sigma-rules\T1053.005_scheduled_task_creation.yml
Splunk alert: "T1053.005 - Scheduled Task Created", runs every hour, severity High.


HUNT 5: T1059.001 ENCODED POWERSHELL

Tactic: Execution (TA0002)
Emulation: powershell.exe -EncodedCommand with a harmless Base64 payload

Hypothesis:
If an attacker runs encoded PowerShell, Sysmon will show powershell.exe with -EncodedCommand
in its command line (EventCode 1), and PowerShell Script Block Logging (Event 4104) will
reveal the decoded command.

Findings:
Sysmon EventCode 1 showed powershell.exe launching another powershell.exe with
-NoProfile -EncodedCommand followed by an unreadable Base64 string.
PowerShell Script Block Logging (Event 4104) recorded the decoded command in clear text:
Write-Output "Hunt5 encoded test"; whoami
The encoding hid the command from the process log, but Script Block Logging revealed it.
Hypothesis confirmed.

Sigma rule: sigma-rules\T1059.001_encoded_powershell.yml
Splunk alert: "T1059.001 - Encoded PowerShell", runs every hour, severity High.


SUMMARY

Five MITRE ATT&CK techniques were emulated with Atomic Red Team or equivalent commands,
hunted in Splunk, and turned into Sigma rules and scheduled Splunk alerts:
T1087.001 Local Account Discovery (Discovery)
T1136.001 Create Local Account (Persistence)
T1547.001 Registry Run Keys (Persistence)
T1053.005 Scheduled Task (Persistence, Execution)
T1059.001 Encoded PowerShell (Execution)
All five hypotheses were confirmed. One benign event was investigated and closed.
